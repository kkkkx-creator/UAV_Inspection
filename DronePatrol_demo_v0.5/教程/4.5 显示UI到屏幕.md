在详细介绍 **Player Controller 方法**之前，我必须先给你一个**非常重要的提醒**：

AirSim 自带了专门的 `AirSimPlayerController`，负责处理键盘控制（WASD 移动、F 键切换视角等）。如果你直接创建一个全新的空白 Player Controller 并设为默认，**你可能会失去所有飞行控制能力**（无人机还能飞，但你的键盘鼠标可能无法操作视角）。

因此，我提供**两种方法**，推荐你优先使用方法 A（最安全、最简单）。我也会按你的要求，把方法 B（Player Controller 方法）讲得极其详细。

---

## 方法 A（强烈推荐）：在关卡蓝图中创建 UI（不改变 Player Controller）

这个方法不需要创建任何 Player Controller 蓝图，不会影响 AirSim 的任何控制功能。

### 详细步骤：

1. **打开你的主关卡**（比如 `Main.umap` 或你运行场景的那个关卡）。
2. 点击 UE4 顶部菜单栏的 **蓝图 (Blueprint)** → **打开关卡蓝图 (Open Level Blueprint)**。
3. 在关卡蓝图的事件图表中，你会看到一个默认的 **Event BeginPlay** 节点（如果找不到，右键搜索 `BeginPlay` 拖出来）。
4. 从 `Event BeginPlay` 的执行引脚（白色箭头）拖出，松开鼠标，在弹出的搜索框中输入 **`Create Widget`**，选择它。
5. 在 `Create Widget` 节点的 **Class** 下拉框中，选择你之前创建的 **`WBP_MultiUAVMonitor`**。
6. 鼠标左键按住 `Create Widget` 节点的 **Return Value**（返回值）引脚拖出，松开，选择 **“提升为变量 (Promote to variable)”**，命名为 **`MonitorUI`**（这样便于在其他地方引用，但不是必须的）。
7. 从 `Create Widget` 节点的执行引脚拖出，搜索 **`Add to Viewport`**，连接到它。
8. **关键一步：让鼠标能操作 UI**。从 `Add to Viewport` 的执行引脚再拖出：
   - 搜索 **`Set Input Mode UI Only`**，连接它。
   - 将 `Create Widget` 节点的 **Return Value** 连接到 `Set Input Mode UI Only` 节点的 **In Widget to Focus** 引脚（这样 UI 按钮可以接收点击）。
   - 再拖出一个节点 **`Set Show Mouse Cursor`**（在Graph中右键，在弹出的复选框中将右上角的“情景关联”，**不勾选**，才能看到 `Set Show Mouse Cursor`），勾选 `Visible` 为 **true**（这样鼠标指针才会显示）。
9. 最终节点连接顺序是：
   `BeginPlay` → `Create Widget` → `Add to Viewport` → `Set Input Mode UI Only` → `Set Show Mouse Cursor`（最后两个顺序可以调换，但都必须连在 `Add to Viewport` 后面）。
10. 点击 **编译 (Compile)** 并 **保存 (Save)**。
11. 关闭关卡蓝图，点击 **Play**。现在你应该能看到 UI 覆盖在游戏画面上，并且可以点击“刷新”按钮（前提是你已经在 `WBP_MultiUAVMonitor` 中实现了刷新逻辑）。

## 方法 B：通过 Player Controller 蓝图创建 UI（按你的要求详细说明）

> **警告（必看）**：如果直接使用下面的步骤创建空白 Player Controller，AirSim 的键盘控制（WASD 移动视角、F 切换相机等）可能会失效。**如果你想保留 AirSim 控制，请在第二步选择父类时，搜索并选择 `AirSimPlayerController`（如果列表中有），或者参考步骤 4 的处理方式。**

### 第一步：创建 Player Controller 蓝图

1. 在 **Content Browser** 中，右键空白处 → **Blueprint Class**。
2. 在弹出的 **Pick Parent Class** 窗口中：
   - **为了保留 AirSim 控制**：在搜索框输入 `AirSim`，如果能找到 **`AirSimPlayerController`**，选择它作为父类（这是最安全的选择）。
   - **如果找不到 AirSimPlayerController**：选择默认的 **`Player Controller`**（这将导致键盘控制丢失，需要在后面手动补充，比较麻烦，不建议）。
3. 命名为 **`BP_DronePlayerController`**，点击创建。

### 第二步：在蓝图中添加 UI 到视口

1. 双击打开 `BP_DronePlayerController`。
2. 在左侧 **我的蓝图 (My Blueprint)** 面板中，点击 **事件图表 (Event Graph)**。
3. 在图表中右键搜索 **`Event BeginPlay`**，拖出节点。
   - **重要**：如果你的父类选择了 `AirSimPlayerController`，这里必须**先调用父类的 BeginPlay**。在图表中右键搜索 **`Parent: BeginPlay`** 节点，将 `Event BeginPlay` 的执行引脚先连接到 `Parent: BeginPlay`，然后再接后面的逻辑。如果是空白 Player Controller 则不需要。
4. 从 `Event BeginPlay`（或 `Parent: BeginPlay` 之后）的执行引脚拖出，搜索 **`Create Widget`**，选择它。
5. 在 `Create Widget` 节点的 **Class** 中，选择 **`WBP_MultiUAVMonitor`**。
6. 将返回值 **提升为变量 (Promote to variable)**，命名为 **`MonitorUI`**（方便后续访问）。
7. 从 `Create Widget` 的执行引脚拖出，搜索 **`Add to Viewport`**，连接它。
8. **鼠标交互设置**（同方法 A）：
   - 从 `Add to Viewport` 拖出 **`Set Input Mode UI Only`**，并将 `Create Widget` 的返回值连接到其 **In Widget to Focus** 引脚。
   - 再拖出 **`Set Show Mouse Cursor`**，勾选 **Visible** 为 true。
9. 编译并保存蓝图。

### 第三步：设置为默认 Player Controller

1. 在 UE4 顶部菜单点击 **编辑 (Edit)** → **项目设置 (Project Settings)**。
2. 在左侧找到 **引擎 (Engine)** → **地图与模式 (Maps & Modes)**。
3. 在右侧的 **默认模式 (Default Modes)** 区域，找到 **默认玩家控制器类 (Default Player Controller Class)**。
4. 点击下拉框，选择你刚创建的 **`BP_DronePlayerController`**。
5. 关闭设置窗口，点击 **Play** 运行。

### 第四步（补救措施）：如果键盘控制失效怎么办？

如果你按方法 B 选择的是空白 `Player Controller`，发现 WASD 无法移动视角，可以尝试在 `BP_DronePlayerController` 的 `Event BeginPlay` 后添加 **`Set Input Mode Game Only`**（而不是 `UI Only`），但这可能让按钮无法点击。折中方案是使用 **`Set Input Mode Game and UI`**，它会同时接收游戏输入和 UI 输入。

对于 AirSim 环境，**最简单还是直接用方法 A（关卡蓝图）**，完全不影响任何控制，且操作更少。

## 两种方法对比

| 方法 | 优点 | 缺点 | 推荐度 |
|------|------|------|--------|
| **A. 关卡蓝图** | 不影响 AirSim 任何控制，操作简单，无需额外蓝图 | UI 随关卡存在，无法跨关卡复用（但演示系统足够） | ⭐⭐⭐⭐⭐ |
| **B. Player Controller** | 适合大型项目，UI 逻辑与控制器绑定，便于管理 | 容易覆盖 AirSim 原生控制，需要额外处理输入模式 | ⭐⭐（不推荐新手） |

---

## 接下来怎么做？

建议你先用 **方法 A（关卡蓝图）** 完成 UI 显示，这样你能以最快速度看到效果。如果后续需要更复杂的管理，再考虑迁移到 Player Controller。

完成这一步后，点击 Play 应该能看到左上角出现“多机状态监控”的 UI 列表，并且随着无人机的飞行，数据会实时更新。如果出现 UI 显示但数据不更新，请检查：
1. `AUAVMonitor` Actor 是否已经拖入场景。
2. 输出日志中是否有 AirSim 连接成功的提示。

如果一切顺利，我们就继续下一步（任务数据集成或控制板开发）！
