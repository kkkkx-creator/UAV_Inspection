### 第一步：创建所需变量（Variables）

在图表界面左侧的 **Variables（变量）** 面板中，点击 `+` 新建两个变量：

1. **变量名**：`UAVMonitorRef`
   - **变量类型**：点击变量类型下拉框，搜索 `AUAVMonitor` 并选择（对象引用）。
   - **默认值**：留空（None）。

2. **变量名**：`UAVItemsMap`
   - **变量类型**：点击下拉框 → 搜索 `Map` → 选择 **Map（键值对）**。
   - 在弹出的窗口中，**Key Type（键类型）** 选择 `Int`（整数）；**Value Type（值类型）** 搜索 `WBP_UAVListItem`（对象引用）。
   - **默认值**：留空（空 Map）。

3. **可选变量**：如果你还没给 `LastUpdateText` 和 `UAVListScrollBox` 命名，请在 Hierarchy（层级）中选中它们，在右侧 Details（细节）面板顶部将 **Is Variable** 勾选上，分别命名为 `LastUpdateText` 和 `UAVListScrollBox`。

### 第二步：在 Event Construct 中初始化（绑定数据源）

`Event Construct` 是 Widget 被创建时触发的事件。在图表中右键，搜索 `Construct` 并添加此事件节点。

#### 2.1 获取场景中的 `AUAVMonitor` Actor
- 从 `Event Construct` 节点拉出蓝线（执行线）。
- 右键搜索 **`Get All Actors of Class`** 节点。
- 在节点上选择类：`AUAVMonitor`。
- 拉出该节点返回的 **`Out Actors`（数组）** 引脚。
- 右键搜索 **`Get (a copy)`** 节点（这是取数组元素的节点），索引值填 **`0`**。
- 将这个元素连接到一个 **`Cast To AUAVMonitor`** 节点（因为返回的是 Actor 基类，需要转换）。
- 将转换成功的输出赋值给变量：右键点击 `UAVMonitorRef` 变量，选择 **`Set UAVMonitorRef`**，连接到 Cast 节点的 `As AUAVMonitor` 引脚。

> **注意**：如果编译报错提示“未找到 AUAVMonitor”，说明 C++ 还没编译好，先回 VS 编译一下。

#### 2.2 绑定委托事件（核心）
- 从 `UAVMonitorRef` 变量拖出引脚（确保已经 `Set` 赋值了）。
- 搜索 **`Bind Event to OnUAVStateUpdated`**（这是 C++ 中定义的委托）。
- 这个节点会**自动生成一个事件节点**（通常叫 `OnUAVStateUpdated` 事件，或者让你输入一个事件名称）。把这个自动生成的事件命名为 **`OnStateUpdated`**。
- **（关键）** 现在图表中有了两个东西：一个 `Bind` 节点，一个叫做 `OnStateUpdated` 的事件节点。
  - 将 `Event Construct` 的执行线连接到 `Bind` 节点的输入 `Target` 引脚。
  - `Bind` 节点的 `Event` 引脚，连接到 `OnStateUpdated` 事件节点左侧的白色执行引脚。
  - 这样绑定就完成了：当 C++ 广播数据时，这里的 `OnStateUpdated` 事件就会被自动触发。

##### UE4.27的另一个限制

这是 UE4.27 Widget Blueprint 的一个特殊限制。手动右键创建的自定义事件**没有委托签名**，所以和Bind节点的类型对不上。

###### 正确做法：从 `Event` 引脚拖线创建

1. **删除**你手动创建的 `OnStateUpdated` 自定义事件

2. 从 **`Bind Event to OnUAVStateUpdated`** 节点的 `Event` 引脚（红色小正方形）**往外拖线到画布的空白处**

3. 弹出的菜单顶部会出现 **"Add Custom Event"**（或"创建自定义事件"），点击它

4. 给这个自动生成的事件命名为 `OnUAVStateUpdated`

这样创建出来的事件节点**自动带有正确的委托签名**，参数 `NewState (UAVState)` 也会自动生成，不需要手动加。

###### 为什么两种方式不一样？

| 创建方式 | 结果 |
|----------|------|
| 右键画布 → Add Custom Event | 普通事件，无委托签名 → 连不上 |
| 从 Bind 的 Event 引脚拖出 → Add Custom Event | 带委托签名的匹配事件 → 可以直接连 |

从 `Event` 引脚拖出来创建，UE 知道你要创建一个能匹配 `FOnUAVStateUpdated` 委托的事件，所以自动帮你配好了签名和参数。

###### 重命名回去：刷新蓝图
1. 点击蓝图左上角 Compile（编译）
2. 关闭并重新打开 Widget Blueprint
3. 重命名为 OnStateUpdated

#### 2.3 第一次手动刷新（显示初始数据）
- 从 `Event Construct` 的执行线继续往下拉。
- 调用 `UAVMonitorRef` 的 **`ForceUpdate`** 函数（右键搜索 `Force Update`，或者在 `UAVMonitorRef` 引脚上拖出搜索 `ForceUpdate`）。
- 连接执行线。

### 第三步：实现核心更新逻辑（OnStateUpdated 事件）

现在点击图表中的 `OnStateUpdated` 事件节点，我们来实现当收到无人机状态时怎么处理。

这个事件带有一个输入参数：**`NewState`**（类型为 `FUAVState`，里面包含无人机 ID、位置等信息）。

#### 3.1 检查该无人机是否已经在列表中（查 Map）
- 从 `NewState` 引脚拖出，搜索 **`Break FUAVState`**，获得 `UAVId` 等字段。
- 从 `UAVItemsMap` 变量拖出，搜索 **`Contains`** 节点（用于检查 Map 中是否包含某个键）。
- 将 `Break` 出来的 `UAVId` 连接到 `Contains` 节点的 `Key` 引脚。
- 拉出 `Contains` 节点的返回值（布尔值），连接到 **`Branch`（分支）** 节点的条件输入（Condition）。

#### 3.2 分支 A：已存在（更新数据）
- 如果 `Branch` 为 **True**（无人机已在列表中）：
  - 从 `UAVItemsMap` 变量拖出，搜索 **`Find`** 节点（查找键对应的值）。
  - 将 `UAVId` 连接到 `Find` 节点的 `Key` 引脚。
  - `Find` 节点的输出 `Value` 就是已有的那个 `WBP_UAVListItem` 实例。
  - 在这个 `Value` 上，调用 **`SetUAVState`**（这是我们之前在列表项里写的函数）。
  - 将 `NewState`（完整结构体）连接到 `SetUAVState` 的 `InState` 输入引脚。

#### 3.3 分支 B：不存在（创建新条目）
- 如果 `Branch` 为 **False**（第一次见到这架无人机）：
  1. **创建 Widget**：右键搜索 **`Create Widget`**，类选择 `WBP_UAVListItem`，保存到局部变量 `NewItem`。
  2. **设置数据**：在 `NewItem` 上调用 **`SetUAVState`**，传入 `NewState`。
  3. **添加到滚动框**：从 `UAVListScrollBox` 变量拖出，调用 **`Add Child`** 节点。将 `NewItem` 连接到 `Add Child` 的 `Content` 引脚。
  4. **存入 Map**：从 `UAVItemsMap` 变量拖出，调用 **`Add`** 节点。`Key` 填 `NewState.UAVId`，`Value` 填 `NewItem`。

#### 3.4 更新时间戳
- 拉一条独立的执行线（或在最后）。
- 右键搜索 **`Now`** 节点（获取当前日期时间），将其转换为字符串（调用 `ToString`）。
- 设置 `LastUpdateText` 的文本（`Set Text`），内容为 `"最后更新: " + 时间字符串`。

### 避坑指南（特别留意）

| 易错点 | 正确做法 |
| :--- | :--- |
| **Map 的 Find 节点用法** | 蓝图中的 `Find` 节点有两个输出：`Is Valid`（是否找到）和 `Value`（值）。建议在 Branch 之后用，如果为 True 再拿 `Value`。不要直接拿 `Value`，因为找不到会报空指针。 |
| **Add Child 后 UI 不刷新** | 检查 `UAVListScrollBox` 的 **`Orientation`**（方向）是否设置为 `Vertical`（垂直），以及是否允许滚动。 |
| **绑定事件后不触发** | 检查 C++ 中的 `OnUAVStateUpdated.Broadcast(NewState);` 是否被执行（设置断点或输出日志）。另外，确保 `Event Construct` 里的 `Bind` 节点执行过了。 |
| **列表项颜色不变化** | 需要在 `WBP_UAVListItem` 的 `SetUAVState` 里，用 `Set Color and Opacity` 或 `Set Brush Color` 节点动态修改 Border 和文字颜色。 |
