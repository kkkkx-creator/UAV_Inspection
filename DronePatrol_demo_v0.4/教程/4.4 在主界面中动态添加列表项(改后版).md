好的，针对 UE4.27 中 UMG Widget 不支持 `Map` 类型变量的限制，我们需要用两个 `Array` 来模拟键值对存储。这里有两种方案：

1. **两个并行 Array**：一个 `Int` 数组存储 UAVId，一个 `WBP_UAVListItem` 数组存储对应的列表项控件。通过索引位置一一对应。
2. **单个结构体 Array**：定义一个包含 `UAVId` 和 `Widget` 引用的结构体，然后使用这个结构体的数组。

推荐**方案一**，因为它更直接，在蓝图中操作更简单（不需要额外定义结构体）。下面给出完整的 4.4 步骤替换方案。

## 修改后的 4.4：在主界面中动态添加列表项（使用两个 Array）

### 步骤 1：创建替代变量（替代原来的 Map）

在 `WBP_MultiUAVMonitor` 的 Variables 面板中创建两个变量：

1. **变量名**：`UAVIdArray`
   - 类型：**Array**（点击下拉框，搜索 `Array`，选择“数组”）。
   - 值类型：选择 **`Int`**（整数）。
   - 默认值：空。

2. **变量名**：`UAVItemArray`
   - 类型：**Array**。
   - 值类型：选择 **`WBP_UAVListItem`**（对象引用）。
   - 默认值：空。

同时保留 `UAVMonitorRef` 变量（类型 `AUAVMonitor` 对象引用）。

#### 关于 Array 类的说明

在 UE 4.27 中，创建 Array 变量的方式和教程写的不太一样。**Array 不是一种"类型"，而是把普通类型变成数组的一个开关。**

##### 两步操作

###### 步骤一：先选基础类型

创建变量后，在类型下拉框中先选**基础类型本身**：

| 变量 | 先选什么类型 |
|------|------------|
| `UAVIdArray` | 先选 **`Integer`**（在结构体列表里找） |
| `UAVItemArray` | 先选 **`WBP_UAVListItem`**（在对象类型里找） |

###### 步骤二：点击数组开关

选好基础类型后，**看变量类型那一行的右边**，有一个类似 **`[三]`** 或 **`三横线`** 的小图标按钮——那个就是"转为数组"的开关。

点一下，类型框里的 `Integer` 就会变成 **`Array of Integer`**，`WBP_UAVListItem` 就会变成 **`Array of WBP_UAVListItem`**。

```
变量类型: [Integer ▼]  [三]   ← 点这个图标
                          ↑
                    点了之后变成:

变量类型: [Array of Integer ▼]  [三]
```

###### 简单来说

教程里写"搜索 Array"是 UE5 的用法。UE4.27 中必须**先选好基础类型 → 再点右边的数组按钮**，两步分开做。

### 步骤 2：在 Event Construct 中获取并绑定数据源（与之前相同）

- 获取 `AUAVMonitor` 实例，赋值给 `UAVMonitorRef`。
- 绑定 `OnUAVStateUpdated` 委托到自定义事件 `OnStateUpdated`。
- 调用 `ForceUpdate()` 初次更新。

这部分操作和原方案完全一致，只是后续查找逻辑不同。

---

### 步骤 3：编写 `OnStateUpdated` 事件（核心查找逻辑）

`OnStateUpdated` 事件接收参数 `NewState`（类型 `FUAVState`）。我们需要根据 `NewState.UAVId` 在 `UAVIdArray` 中查找，如果找到则更新对应索引的 `UAVItemArray` 元素，否则添加新条目。

#### 3.1 从 `NewState` 中获取 `UAVId`

- 拖出 `NewState` 引脚 → 搜索 `Break FUAVState` 节点 → 得到 `UAVId`。

#### 3.2 遍历 `UAVIdArray` 查找匹配的 Id

- 从 `UAVIdArray` 变量拖出 → 搜索 **`ForEachLoop`** 节点（数组遍历）。这会生成一个循环，每次迭代输出 `Array Element`（当前 Id）和 `Index`（索引）。
- 将 `Break` 出来的 `UAVId` 与 `Array Element` 进行比较（使用 `==` 节点，注意类型都是 Int）。
- 将比较结果（布尔值）连接到 `Branch`（分支）节点的条件输入。

#### 3.3 分支处理

- **如果找到（Branch True）**：
  - 使用 `Index` 去 `UAVItemArray` 中取出对应的列表项控件：从 `UAVItemArray` 变量拖出，搜索 **`Get (Copy)`** 节点，索引连接 `Index`，得到的控件引用。
  - 在该控件上调用 **`SetUAVState`**，传入 `NewState`。
  - 然后跳出循环（可使用 **`Break`** 节点，连接在 `Branch` 的 True 执行线上，但要注意循环体内使用 Break 会终止整个 ForEachLoop）。

- **如果未找到（Branch False）**：
  - 当循环结束后（即 `ForEachLoop` 的 Completed 引脚），如果没有匹配到，说明是新无人机。
  - 在 Completed 引脚后面执行创建新条目的逻辑（需要确保只有在未找到的情况下才执行，因此我们将创建逻辑放在循环完成后，并使用一个标志变量判断是否找到了）。

> **重要**：因为 `ForEachLoop` 是异步的（但蓝图中的 ForEachLoop 是同步完成的，只是有 Completed 引脚），我们需要在循环内部设置一个“是否找到”的标志。最简单的方法：在循环开始前设置一个局部布尔变量 `Found` = false，在 True 分支中将其设为 true，然后在 Completed 引脚判断 `Found`，如果为 false 则创建。

#### 3.4 实现方式（更优雅）

为了避免在 Completed 引脚判断标志，我们可以采用另一种方式：直接使用 `ForEachLoop` 的 `Index` 来取元素，但 `ForEachLoop` 无法提前获取匹配索引。最佳实践是使用一个 **`Find`** 节点，但 `Find` 节点需要数组和要查找的值，并且需要相等性比较，但 `Find` 只能查找值，不能自定义条件。所以我们必须手动遍历。

为了实现“未找到则创建”，我们采用如下蓝图结构：

- 从 `UAVIdArray` 变量拖出，调用 **`Length`** 节点获取数组长度，然后用一个 `ForLoop` 整数循环（从 0 到 Length-1），在循环体内用 `Get (Copy)` 获取对应 Id，与目标比较，如果相等则更新并设置一个布尔变量 `bFound = true`，然后 `Break` 跳出循环。
- 循环结束后，判断 `bFound`，如果为 false 则创建新条目。

这样逻辑清晰可控。下面详细描述。

---

### 步骤 4：具体节点连线（详细版）

#### 4.1 在 `OnStateUpdated` 中分解 `NewState`

- 添加 `Break FUAVState` 节点，输出 `UAVId` 等。
- 将 `UAVId` 存入一个局部变量（或直接使用连线）。

#### 4.2 设置查找变量

- 创建一个局部布尔变量 `bFound`，初始值 false（在事件图表中右键 → `Add Local Variable`，命名为 `bFound`，类型 Boolean）。
- 或者直接拖出一个 `Boolean` 节点设为 false，然后 `Set` 到变量。

#### 4.3 遍历数组

- 从 `UAVIdArray` 拖出，调用 **`Length`** 节点。
- 使用 **`ForLoop`** 节点（整数循环），设置起始 0，结束 Length-1。
- 在循环体内（Loop Body 引脚）：
  - 从 `UAVIdArray` 拖出，调用 **`Get (Copy)`**，Index 输入循环的 `Index` 输出引脚。
  - 比较该 Id 与目标 `UAVId`，结果连接到 `Branch`。
  - **如果相等（True）**：
    - 从 `UAVItemArray` 拖出，调用 **`Get (Copy)`**，同样使用 `Index`，得到对应的列表项控件。
    - 调用该控件的 `SetUAVState`，传入 `NewState`。
    - 设置 `bFound = true`。
    - 使用 **`Break`** 节点（在 Flow Control 类别中）跳出循环（连接到 `Branch` 的 True 执行线后）。
  - **如果不相等（False）**：什么都不做，继续循环。

#### 4.4 循环结束后（Completed 引脚）

- 判断 `bFound`，如果为 false：
  - **创建新 Widget**：`Create Widget`（类 WBP_UAVListItem）→ 存入局部变量 `NewItem`。
  - **设置数据**：`NewItem->SetUAVState(NewState)`。
  - **添加到滚动框**：从 `UAVListScrollBox` 变量拖出，调用 `Add Child`，Content 为 `NewItem`。
  - **更新数组**：
    - 将 `UAVId` 添加到 `UAVIdArray`（调用 `Add` 节点）。
    - 将 `NewItem` 添加到 `UAVItemArray`（调用 `Add` 节点）。
    - 注意：两个数组的添加顺序要同步，确保索引一致。

#### 4.5 更新时间戳

- 同原方案：获取当前时间并设置 `LastUpdateText`。

### 步骤 5：实现“刷新”按钮

- 在 `RefreshBtn` 的 `OnClicked` 事件中调用 `UAVMonitorRef->ForceUpdate()`。

## 注意事项

| 问题 | 解决 |
|------|------|
| 循环中修改数组（添加）会不会影响正在遍历的数组？ | 不会，因为我们在循环结束后才添加新元素，循环期间不修改数组。 |
| 如果无人机数量很多，遍历会不会慢？ | 对于 4~10 架无人机，性能影响微乎其微。演示系统完全够用。 |
| 如何确保两个数组索引一致？ | 添加时同时 `Add`，删除时同时 `RemoveAt`（本场景不会删除无人机，所以不用考虑删除）。 |
| 如果无人机 ID 不连续（例如 UAV1, UAV3）？ | 查找只依赖 ID 匹配，不依赖连续性，所以没问题。 |

## 替代方案：使用结构体数组

如果你觉得两个数组操作起来容易出错，也可以定义一个结构体：

- 创建结构体 `FUAVItemPair`，包含 `int32 UAVId` 和 `WBP_UAVListItem* Widget`。
- 然后在 UMG 中声明一个该结构体的数组变量。
- 在查找时遍历数组，比较 `UAVId`。

但结构体数组在 UMG 中可用，需要额外定义结构体（在 Content Browser 中创建），稍微麻烦一些。两个 Array 方案更直观，不需要定义额外类型。
