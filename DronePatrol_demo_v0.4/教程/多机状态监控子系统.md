## 第一步：配置项目依赖（编译 C++ 所需）

由于需要调用 AirSim 的 C++ API，必须在项目的 `Build.cs` 中添加对 `AirSim` 模块的依赖。

1. 打开文件：`Dronepatrol_demo/Source/DronePatrol_demo/DronePatrol_demo.Build.cs`
2. 在构造函数中找到 `PublicDependencyModuleNames` 或 `PrivateDependencyModuleNames`，添加 `"AirSim"`。
3. 最终效果如下：

```csharp
// Fill out your copyright notice in the Description page of Project Settings.

using UnrealBuildTool;

public class DronePatrol_demo : ModuleRules
{
```

4. 重新生成项目文件：右键点击 `DronePatrol_demo.uproject` → **Generate Visual Studio project files**。

## 第二步：创建 C++ 数据结构和 UAV 管理器 Actor

我们会创建一个 Actor 类 `AUAVMonitor`，它负责：
- 连接 AirSim
- 轮询每架无人机的状态（位置、速度、电量、任务状态等）
- 通过 UE 的委托（Delegate）将数据广播给 UI。

### 2.1 创建 C++ 类

1. 在 UE 编辑器菜单栏：**Tools → New C++ Class**。
2. 选择父类：`Actor`，点击 Next。
3. 命名：`UAVMonitor`，点击 Create Class。
4. 编辑器会自动创建两个文件：
   - `Source/DronePatrol_demo/UAVMonitor.h`
   - `Source/DronePatrol_demo/UAVMonitor.cpp`

### 2.2 编写头文件 `UAVMonitor.h`

完全替换为以下内容：

```cpp
// Fill out your copyright notice in the Description page of Project Settings.

#pragma once

#include "CoreMinimal.h"
#include "GameFramework/Actor.h"
#include "UAVMonitor.generated.h"

// 无人机状态结构体（可在蓝图中直接使用）
USTRUCT(BlueprintType)
struct FUAVState
{
    GENERATED_BODY()

    UPROPERTY(BlueprintReadOnly)
    int32 UAVId = 0;

    UPROPERTY(BlueprintReadOnly)
    FVector Position = FVector::ZeroVector;

    UPROPERTY(BlueprintReadOnly)
    float BatteryPercent = 100.0f;

    UPROPERTY(BlueprintReadOnly)
    float SpeedKmh = 0.0f;

    UPROPERTY(BlueprintReadOnly)
    FString TaskStatus = TEXT("Idle");

    UPROPERTY(BlueprintReadOnly)
    FString TaskType = TEXT("None");

    UPROPERTY(BlueprintReadOnly)
    float TaskProgress = 0.0f;

    UPROPERTY(BlueprintReadOnly)
    bool bHasFault = false;

    UPROPERTY(BlueprintReadOnly)
    FString FaultType = TEXT("");
};

// 声明多播委托，当状态更新时触发（蓝图可绑定）
DECLARE_DYNAMIC_MULTICAST_DELEGATE_OneParam(FOnUAVStateUpdated, const FUAVState&, NewState);

UCLASS()
class DRONEPATROL_DEMO_API AUAVMonitor : public AActor
{
    GENERATED_BODY()

public:
    AUAVMonitor();

protected:
    virtual void BeginPlay() override;
    virtual void EndPlay(const EEndPlayReason::Type EndPlayReason) override;

public:
    // 供UI绑定的委托
    UPROPERTY(BlueprintAssignable, Category = "UAVMonitor")
    FOnUAVStateUpdated OnUAVStateUpdated;

    // 获取所有无人机的最新状态快照（供蓝图直接读取）
    UFUNCTION(BlueprintCallable, Category = "UAVMonitor")
    TArray<FUAVState> GetAllUAVStates() const { return CachedUAVStates; }

    // 手动强制刷新一次
    UFUNCTION(BlueprintCallable, Category = "UAVMonitor")
    void ForceUpdate();

private:
    // 更新所有无人机状态
    void UpdateAllUAVStates();

    // 获取某架无人机的电量（示例实现）
    float GetBatteryPercentage(const FString& VehicleName);

    // 从AirSim客户端获取状态的核心函数
    void FetchStateFromAirSim(int32 UAVId, const FString& VehicleName, FUAVState& OutState);

    // 缓存的无人机状态列表
    TArray<FUAVState> CachedUAVStates;

    // 定时器句柄
    FTimerHandle UpdateTimerHandle;

    // 前向声明 AirSim 客户端指针（使用智能指针，避免暴露完整类型）
    class msr::airlib::MultirotorRpcLibClient* AirSimClient;
};
```

### 2.3 编写实现文件 `UAVMonitor.cpp`

```cpp
// Fill out your copyright notice in the Description page of Project Settings.

#include "UAVMonitor.h"
#include "Engine/World.h"
#include "TimerManager.h"
#include "DrawDebugHelpers.h"

// 包含 AirSim 的 C++ 客户端头文件
#include "vehicles/multirotor/api/MultirotorRpcLibClient.hpp"
#include "common/common_utils/Utils.hpp"

// 由于 AirSim 插件可能不会自动暴露所有头文件路径，需要确保编译时能找到。
// 通常 AirSim 插件的 Public 目录已添加到模块路径中。

AUAVMonitor::AUAVMonitor()
{
    PrimaryActorTick.bCanEverTick = false;   // 使用定时器，不需要每帧Tick
    AirSimClient = nullptr;
}

void AUAVMonitor::BeginPlay()
{
    Super::BeginPlay();

    // 创建 AirSim 客户端实例
    AirSimClient = new msr::airlib::MultirotorRpcLibClient();
    
    // 尝试连接，等待 5 秒
    AirSimClient->confirmConnection(5.0f);
    UE_LOG(LogTemp, Log, TEXT("UAVMonitor: Connected to AirSim."));

    // 启动定时器，每隔 0.5 秒更新一次状态
    GetWorldTimerManager().SetTimer(UpdateTimerHandle, this, &AUAVMonitor::UpdateAllUAVStates, 0.5f, true);
}

void AUAVMonitor::EndPlay(const EEndPlayReason::Type EndPlayReason)
{
    // 清理定时器
    GetWorldTimerManager().ClearTimer(UpdateTimerHandle);
    
    // 断开并删除客户端
    if (AirSimClient)
    {
        AirSimClient->~MultirotorRpcLibClient();
        delete AirSimClient;
        AirSimClient = nullptr;
    }
    
    Super::EndPlay(EndPlayReason);
}

void AUAVMonitor::ForceUpdate()
{
    UpdateAllUAVStates();
}

void AUAVMonitor::UpdateAllUAVStates()
{
    if (!AirSimClient) return;

    // 这里定义你想要监控的无人机名称列表（需与 AirSim settings.json 中配置的一致）
    // 例如："UAV1", "UAV2", "UAV3", "UAV4"
    TArray<FString> VehicleNames = { TEXT("UAV1"), TEXT("UAV2"), TEXT("UAV3"), TEXT("UAV4") };
    
    CachedUAVStates.Empty();
    for (int32 i = 0; i < VehicleNames.Num(); ++i)
    {
        const FString& Name = VehicleNames[i];
        FUAVState NewState;
        NewState.UAVId = i + 1;
        FetchStateFromAirSim(NewState.UAVId, Name, NewState);
        CachedUAVStates.Add(NewState);
        
        // 广播委托，让绑定的 UI 实时更新
        OnUAVStateUpdated.Broadcast(NewState);
    }
}

void AUAVMonitor::FetchStateFromAirSim(int32 UAVId, const FString& VehicleName, FUAVState& OutState)
{
    if (!AirSimClient) return;

    std::string VehicleNameStd = TCHAR_TO_UTF8(*VehicleName);
    try
    {
        // 获取多旋翼状态
        auto rotorState = AirSimClient->getMultirotorState(VehicleNameStd);
        auto pos = rotorState.getPosition();      // Vector3r
        auto vel = rotorState.getVelocity();      // Vector3r

        // 位置 (AirSim 坐标系: X, Y, Z  与 UE4 坐标系一致，但注意 Z 向上)
        OutState.Position = FVector(pos.x(), pos.y(), pos.z());
        
        // 速度 (m/s → km/h)
        float speedMPS = FVector(vel.x(), vel.y(), vel.z()).Size();
        OutState.SpeedKmh = speedMPS * 3.6f;

        // 获取电量: AirSim 没有直接提供百分比，可以通过 BatteryVoltage 估算
        OutState.BatteryPercent = GetBatteryPercentage(VehicleName);

        // ---------- 模拟任务状态（实际需从你的任务管理模块获取）----------
        // 这里先写死示例数据，后续可替换为真实任务系统
        OutState.TaskStatus = TEXT("En Route");
        OutState.TaskType = TEXT("Point");
        OutState.TaskProgress = FMath::RandRange(0.0f, 1.0f);
        
        // ---------- 故障检测（基于电量/速度/模拟）----------
        OutState.bHasFault = false;
        OutState.FaultType = TEXT("");
        if (OutState.BatteryPercent < 15.0f)
        {
            OutState.bHasFault = true;
            OutState.FaultType = TEXT("Low Battery");
        }
        else if (OutState.SpeedKmh > 80.0f)
        {
            OutState.bHasFault = true;
            OutState.FaultType = TEXT("Excessive Speed");
        }
        // 也可以随机触发其他故障用于演示（生产环境取消）
        // else if (FMath::FRand() < 0.02f) { ... }
    }
    catch (const std::exception& e)
    {
        UE_LOG(LogTemp, Warning, TEXT("AirSim exception for %s: %s"), *VehicleName, UTF8_TO_TCHAR(e.what()));
        OutState.bHasFault = true;
        OutState.FaultType = TEXT("Communication Lost");
    }
}

float AUAVMonitor::GetBatteryPercentage(const FString& VehicleName)
{
    if (!AirSimClient) return 100.0f;
    
    // 尝试获取电池电压（假设满电 12.6V，低电 10.5V）
    try
    {
        std::string name = TCHAR_TO_UTF8(*VehicleName);
        // AirSim 的 getBatteryVoltage 需要车辆名称，但不同版本 API 可能不同，这里用安全方式
        // 如果没有此方法，则返回模拟值
        auto voltages = AirSimClient->getBatteryVoltage(name);
        float voltage = voltages.size() > 0 ? voltages[0] : 12.0f;
        float percent = (voltage - 10.5f) / (12.6f - 10.5f) * 100.0f;
        return FMath::Clamp(percent, 0.0f, 100.0f);
    }
    catch (...)
    {
        // 如果 API 不可用，返回随机值用于演示
        return FMath::RandRange(60.0f, 100.0f);
    }
}
```

> **注意**：`getBatteryVoltage` 可能在你的 AirSim 版本中不可用。如果编译出错，请注释掉该部分，改为返回模拟值（如 80~100%）。演示系统中也可以使用随机值。

```json

      "VehicleType": "SimpleFlight",
```

### 4.2 创建列表项 `WBP_UAVListItem`

1. 创建另一个 Widget Blueprint，命名为 `WBP_UAVListItem`。
2. 设计此条目的布局（参考之前的方案）：

```
Border (根，命名为ItemBorder)
├── HorizontalBox
    ├── Image (StatusIcon，大小32x32，颜色根据状态变化)
    ├── VerticalBox
        ├── TextBlock (UAVNameText，字号18，粗体)
```

3. 在 `WBP_UAVListItem` 的 **Graph** 中创建以下函数（用于外部填充数据）：

- **函数名**：`SetUAVState`
- **输入参数**：`UAVState`（类型为自行导入的 `FUAVState` 结构体，需要先包括头文件）。

如何导入结构体：在蓝图的 **Variables** 面板中，点击 **New Variable**，然后选择类型时展开 **Structs**，搜索 `FUAVState`。若没有出现，需要先编译 C++ 代码。

**蓝图节点逻辑**（文字描述，实际按图连接）：

1. `SetUAVState` → 从传入的 `UAVState` 中 Break 出各个字段。
2. 设置 `UAVNameText` 的文本为 `"UAV " + IntToString(UAVId)`。
3. 设置 `BatteryText` 为 `"电量: " + FloatToString(BatteryPercent) + "%"`。
4. 设置 `SpeedText` 为 `"速度: " + FloatToString(SpeedKmh) + " km/h"`。
5. 设置 `PositionText` 为 `"位置: (" + FloatToString(Position.X) + ", " + FloatToString(Position.Y) + ", " + FloatToString(Position.Z) + ")"`。
6. 设置 `TaskText` 为 `"任务: " + TaskType + " | " + FloatToString(TaskProgress*100) + "%"`。
7. 若 `bHasFault` 为真：设置 `FaultText` 可见，内容为 `"? " + FaultType`；并设置 `ItemBorder` 的边框颜色为红色；`StatusIcon` 颜色红色。
8. 若电量低于 20% 且无故障：边框黄色，电量文字橙色。
9. 否则正常：边框绿色，故障文字隐藏。

**注意**：需要将 `ItemBorder` 的 Brush Color 设置为可变，可以在 Brush 的 Tint Color 引脚上设置。

### 4.3 在主界面中动态添加列表项

1. 打开 `WBP_MultiUAVMonitor` 的 **Graph**。
2. 添加变量：
   - 类型 `AUAVMonitor` 的变量 `UAVMonitorRef`（默认值 None，在 Event Construct 中获取）。
   - 类型 `Array` 的 `UAVListItems`，元素类型为 `WBP_UAVListItem`（用于管理已生成的条目）。
3. 重写 `Event Construct`（在 **Event Graph** 中搜索 "Construct"）：
   - 获取游戏中的所有 Actor 的类 `AUAVMonitor`，使用 `Get All Actors of Class` 节点，得到数组，取第一个（或生成一个新的）。
   - 如果没找到，可以在 `BeginPlay` 时通过 `Spawn Actor` 生成一个（后面第五步会确保场景中已放置）。
   - 将结果赋值给 `UAVMonitorRef`。
   - 绑定事件：`UAVMonitorRef` 的 `OnUAVStateUpdated` 事件 → 自定义事件 `OnUAVStateUpdatedHandler`。
4. 创建自定义事件 `OnUAVStateUpdatedHandler`，输入参数 `NewState (FUAVState)`：
   - 查找已有的列表中是否有相同 `UAVId` 的条目：
     - ForEachLoop 遍历 `UAVListItems`，如果某个条目的 `UAVId` 匹配，调用该条目的 `SetUAVState`，并返回。
   - 如果未找到，则创建新条目：
     - `Create Widget` (Class: `WBP_UAVListItem`) → 结果存入变量 `NewItem`。
     - 调用 `NewItem->SetUAVState(NewState)`。
     - 将 `NewItem` 添加到 `UAVListScrollBox` 中（使用 `Add Child`）。
     - 将 `NewItem` 添加到 `UAVListItems` 数组。
5. `RefreshBtn` 的点击事件：调用 `UAVMonitorRef->ForceUpdate()`。

## 常见问题与解决

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 编译报错 `"vehicles/multirotor/api/MultirotorRpcLibClient.hpp" not found` | Build.cs 未添加 AirSim 依赖或头文件路径未导出 | 检查 .Build.cs 中是否添加了 `"AirSim"`；重新生成项目。 |
| 运行时 `AirSimClient->confirmConnection` 卡死或超时 | AirSim 插件未启动或 settings.json 错误 | 确保播放前 AirSim 环境正常（先测试单机能否控制）。 |
| UI 无法显示 UAV 数据 | UAVMonitor Actor 未在场景中或委托未绑定 | 在关卡中手动放置一个 `UAVMonitor`；检查蓝图绑定逻辑。 |
| 只能看到一架无人机 | settings.json 未配置多机 | 配置好 `Vehicles` 字段，重启编辑器。 |
