好的，这部分是蓝图可视化脚本中**最核心、最繁琐**的数据处理环节。很多刚接触蓝图的朋友会卡在这里，因为 **文本拼接** 在蓝图里不像代码那样直接用 `+` 连接，而是需要**节点连线**。

为了让你彻底看懂，我把两种方法（**Append 拼接法** 和 **Format Text 格式化法**）都用 **“手把手点击操作”** 的方式拆解开，并特别讲解 **“执行线（白线）”** 和 **“数据线（彩线）”** 的区别。

---

### ? 核心预备知识：蓝图的“线”是什么意思？

在蓝图中，你拖出来的线分两种：

1. **白色细线（执行线/流程线）**：控制先后顺序，从左到右流动，像代码中的分号 `;`。
2. **彩色粗线（数据线）**：传递数值/文本，颜色随类型变化（字符串是粉色/紫色，整数是蓝色，浮点是青色）。

**关键规则**：你必须先用 **白色执行线** 触发 `Set Text` 节点，它才会去读取传入的 **彩色数据线** 上的文本内容。

---

### 方法一：使用 `Append`（适合两三个简单拼接）

以 **UAVNameText**（显示 `"UAV 1"`）为例，演示标准拆解步骤：

1. **分解数据**：从 Break 节点拉出 **`UAVId`**（整数类型，蓝色引脚）。
2. **整数转文本**：拉出 `UAVId` 引脚，松开，输入 `Int to Text`（注意是 **Text** 不是 String，UMG 控件认 `Text`）。点击生成节点。此时它输出一个粉色/紫色的 `Text` 变量。
3. **创建常量文本**：在图表空白处 **右键点击**，直接输入 `"UAV "`（**带英文双引号**）。回车，生成一个 **Text 常量节点**。
4. **拼接**：
   - 从 `"UAV "` 常量节点的输出引脚（右侧）拉线，搜索 **`Append`**（追加）。
   - 将 `Int to Text` 节点的输出引脚连接到 `Append` 节点的 **`A`** 或 **`B`** 引脚（不分先后）。
   - 此时 `Append` 节点右侧的输出引脚，就是合并好的 `"UAV 1"` 文本。
5. **赋值给控件**：
   - 从 `Append` 右侧的输出引脚拉线，搜索 **`Set Text (UAVNameText)`**（前提是你已经在设计器里把这个控件设为了变量）。
   - **关键一步**：现在你看到 `Set Text` 节点左侧除了 `In Text` 数据输入外，顶部还有一个白色的 **`执行输入`** 引脚。
   - 你必须从函数入口（左侧的 `In` 执行针脚）拉一条 **白线** 连接到 `Set Text` 节点的顶部白色引脚。这样，当函数运行时，才会执行“设置文本”这个动作。

### 方法二：强烈推荐 `Format Text`（解决复杂拼接，告别头晕）

当你遇到 **PositionText**（位置）这种需要拼接 5、6 个片段的情况，如果用 `Append` 会叠成一座高塔，极易出错。**`Format Text`** 是 UE4 专门做文本拼接的“模板工具”，极其好用。

**格式化文本的规则**：`{0}` 代表第一个输入，`{1}` 代表第二个输入，以此类推。

#### 实操步骤（以拼接位置 `(12.3, 45.6)` 为例）：

1. **放置 Format 节点**：右键空白处，搜索 **`Format Text`**，点击生成。
2. **填写模板**：选中该节点，在右侧 **Details（细节）面板** 中，找到 **`Format`** 这一行，输入：
   ```
   位置: ({0}, {1})
   ```
   （注：如果包含 Z 轴，可以写 `位置: ({0}, {1}, {2})`，这样就是三个占位符）。
3. **传入数据**：
   - 从 `Break` 节点拖出 **`Position`**（向量类型，绿色引脚）。
   - 拖出 `Position` 引脚，搜索 **`Break Vector`**，把 X、Y、Z 拆出来。
   - 分别把 X、Y 拉出来，搜索 **`Float to Text`**（转为文本，并设置小数位数，比如 `2` 代表保留两位小数）。
   - 将 X 转换后的 Text，连接到 `Format Text` 节点下方 **`Arguments`** 数组的 **`[0]`** 引脚（对应 `{0}`）。
   - 将 Y 转换后的 Text，连接到 `Arguments` 数组的 **`[1]`** 引脚（对应 `{1}`）。
4. **执行赋值**：`Format Text` 右侧的输出就是拼好的完整文本，直接连到 `Set Text (PositionText)` 上，同样记得拉一根 **白线** 来触发执行。

### 各个控件的具体数据转换要点

| 控件 | 来源数据 | 转换要点（照着做） |
| :--- | :--- | :--- |
| **BatteryText** | `BatteryPercent` (Float) | 1. 拖出 `BatteryPercent` → **`Float to Text`**（设置小数位数为 `0`）。<br>2. 模板写：`电量: {0}%`。 |
| **SpeedText** | `SpeedKmh` (Float) | 1. 拖出 `SpeedKmh` → **`Float to Text`**（设置小数位数为 `0`）。<br>2. 模板写：`速度: {0} km/h`。 |

### ?? 常见新手陷阱（避坑必看）

1. **找不到 `Set Text` 节点**：在设计器中，**必须** 勾选该控件的 `Is Variable`（是变量），否则蓝图里搜不到它。
2. **转换函数用错了**：
   - 一定要用 **`Float to Text`**（浮点数转文本），**不要** 用 `Float to String`。UMG 控件的 `Set Text` 只认 **Text** 格式。用错会导致连线颜色不匹配，插不进去。
3. **忘了连白色执行线**：
   - 很多新手把所有数据线都连好了，唯独忘了把左侧的白色入口线连到 `Set Text` 上。结果数据传进去了，但 UI 没收到“刷新”指令，屏幕上一片空白。
   - **记住**：白线是开关，彩线是内容。先拉白线触发开关，内容才会显示。
4. **`Format Text` 没反应**：记得在 `Format Text` 节点的 **Details（细节）面板** 输入模板文字，直接双击节点本体输入文本是无效的！

### ? 最后给你的实操建议

对于 `PositionText` 和 `TaskText`，**强烈建议使用 `Format Text`**。你只需要写好模板字符串（比如 `位置: ({0}, {1})`），然后把数据逐个塞进数组里即可，极大减少屏幕上的节点数量，逻辑清晰一目了然。
