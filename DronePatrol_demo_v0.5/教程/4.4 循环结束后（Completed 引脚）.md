好的，这部分是“循环结束后处理”的详细连线指南。很多初学者会在**执行顺序**和 **`bFound` 变量的赋值时机**上出错，我会特别强调这两个关键点。

---

### 🔴 前置关键警告（务必先做这一步）

在开始“循环结束后”的逻辑之前，请确保你在**循环体内的 `True` 分支中**做了以下两件事（顺序很重要）：

1. **将 `bFound` 设置为 `True`**（这必须在 `Break` 之前执行）。
2. 调用 `SetUAVState` 更新控件。
3. 然后触发 `Break` 退出循环。

**为什么？** 因为 `Completed` 引脚只有在循环**正常结束**或**被 Break 中断**后才会执行。如果你没有在 `True` 分支中将 `bFound` 设为 `True`，那么即使找到了匹配项，等执行到 `Completed` 时，`bFound` 依然是 `False`，会导致程序错误地创建一个重复的无人机条目。

> **正确顺序**（循环体内）：
> `Branch (True)` → `Set bFound = True` → `SetUAVState` → `Break`

---

### 第一步：连接到 `Completed` 引脚

1. 在 `For Each Loop with Break` 节点的右侧，找到 **`Completed`** 输出引脚（它是一个白色执行引脚）。
2. 从这个引脚拉出一条执行线（按住并拖拽）。

---

### 第二步：判断 `bFound` 的值

1. 松开鼠标，在弹出的搜索框中输入 **`Branch`**（分支），添加一个分支节点。
2. 现在需要将 `bFound` 变量的值连接到这个分支节点的 **`Condition`（条件）** 输入引脚上。
   - 方法一：在 Variables 面板中找到 `bFound` 变量（局部变量），拖拽到图表中，然后将它的输出引脚连接到 `Branch` 的 `Condition` 上。
   - 方法二（更常见）：在 `Branch` 节点的 `Condition` 引脚上右键 → 选择 `Promote to Variable`（提升为变量），然后从下拉列表中选择 `bFound`。

---

### 第三步：处理“未找到”（False）分支

`Branch` 节点有两个输出引脚：`True` 和 `False`。
- **`True`**：说明找到了，什么都不用做（连接一个空的 `Sequence` 或直接不接线即可）。
- **`False`**：说明没找到，需要创建新条目。**请从 `False` 引脚拉出执行线**。

---

### 第四步：创建新的列表项控件

1. 从 `Branch` 的 `False` 引脚拉出执行线。
2. 松开鼠标，搜索 **`Create Widget`**。
3. 在 `Create Widget` 节点的 **`Class`** 下拉菜单中，选择 `WBP_UAVListItem`。
4. **将 `Create Widget` 节点的返回值（输出引脚）提升为局部变量**：
   - 点击 `Create Widget` 节点的返回值引脚（通常标有 `Return Value`），选择 **`Promote to Variable`**（提升为变量）。
   - 在弹出的命名框中，输入 **`NewItem`**。
   - 这样我们就有了一个当前作用域内有效的局部变量来保存这个新控件。

---

### 第五步：设置新控件的数据

1. 从刚才创建的 **`Set`（赋值）NewItem** 节点的右侧输出引脚拉出执行线（因为你刚刚把新控件存进了变量，接下来要使用这个变量）。
2. 从 Variables 面板中拖出 **`NewItem`** 变量到图表中。
3. 从 `NewItem` 变量引脚上拉出一条线，搜索 **`SetUAVState`**。
4. 将这个 `SetUAVState` 节点的左侧执行输入引脚连接到上一步的执行线上。
5. 将 `OnStateUpdated` 事件传来的 **`NewState`**（完整结构体）连接到 `SetUAVState` 的 `InState` 输入引脚上。

---

### 第六步：将控件添加到滚动框（UI 显示）

1. 从 `SetUAVState` 的右侧输出引脚拉出执行线。
2. 在 Variables 面板中找到 **`UAVListScrollBox`**（滚动框变量），拖拽到图表中。
3. 从 `UAVListScrollBox` 引脚上拉出一条线，搜索 **`Add Child`**。
4. 将执行线连接到 `Add Child` 节点的左侧输入引脚。
5. 将局部变量 **`NewItem`** 连接到 `Add Child` 节点的 **`Content`** 输入引脚上。

---

### 第七步：同步更新两个数组（最关键）

为了保持数据一致，必须同时将新 ID 和控件添加到两个数组中，确保它们索引一致。

1. **更新 `UAVIdArray`**：
   - 从 `Add Child` 的右侧输出引脚拉出执行线。
   - 在 Variables 面板中找到 **`UAVIdArray`**，拖拽到图表中。
   - 从该数组引脚拖出，搜索 **`Add`** 节点。
   - 将 `Add` 节点的 **`Item`** 输入引脚，连接到从 `NewState` 分解出来的 **`UAVId`** 上（可以通过 `Break FUAVState` 节点获取）。
   - 将执行线连接到 `Add` 节点的左侧输入引脚。

2. **更新 `UAVItemArray`**：
   - 从 `Add`（上面那个节点）的右侧输出引脚拉出执行线。
   - 在 Variables 面板中找到 **`UAVItemArray`**，拖拽到图表中。
   - 从该数组引脚拖出，搜索 **`Add`** 节点。
   - 将 `Add` 节点的 **`Item`** 输入引脚，连接到局部变量 **`NewItem`**。
   - 将执行线连接到 `Add` 节点的左侧输入引脚。

> **为什么顺序必须固定？**
> 假设你是先加 Id，再加控件。那么索引 0 位置存的是 UAV1 的 Id，索引 0 位置存的是 UAV1 的控件。下次查找时，我们通过 `UAVIdArray` 找索引，再用该索引取 `UAVItemArray` 里的控件，两者必须严格一一对应。

---

说明：
针对“更新数组”这一步（将新数据添加到已有的数组中），你应该选择 **“获取”（Get）**（即“查询”）。

### 为什么选“获取”（Get）而不是“设置”（Set）？

| 操作 | 效果 | 是否适用 |
| :--- | :--- | :--- |
| **获取 (Get)** | 拿到当前数组的**引用**，然后调用 `Add` 节点往里面**追加**新元素。原有的数据（比如 UAV1、UAV2）会被保留。 | ✅ **正确选择** |
| **设置 (Set)** | 用一个新的数组**替换**掉整个旧数组。如果这里用 Set，会导致之前保存的所有无人机数据被清空，只剩下你刚加的这一架。 | ❌ **绝对不能用** |


### 总结口诀

> **修改内容用 Get（获取），整体覆盖才用 Set（设置）。**
> 这里我们是要“追加”内容，所以必须选 **Get**。

如果误选了 `Set`，编译不会报错，但运行时会发现列表里永远只有最后添加的那一架无人机，因为之前的数据都被覆盖掉了。请务必留意。

---

### 第八步：更新时间戳（可选，但建议）

1. 从最后一个 `Add` 节点的右侧输出引脚拉出执行线。
2. 搜索 **`Now`** 节点（获取当前时间）。
3. 调用 `ToString` 将时间转为字符串。
4. 在 Variables 面板中找到 **`LastUpdateText`**（文本控件），拖拽到图表中。
5. 调用 `Set Text (LastUpdateText)`，将拼接好的字符串（“最后更新: ” + 时间字符串）传入。

---

### 完整连线流程图（Block 视图）

```
[Completed 引脚] 
    │
    ▼
[Branch] (条件判断 bFound)
    │
    ├─── True  ──► (什么都不做，线悬空即可)
    │
    └─── False ──► [Create Widget] (类: WBP_UAVListItem) 
                        │
                        ▼ (保存为局部变量 NewItem)
                   [SetUAVState] (传入 NewState)
                        │
                        ▼
                   [UAVListScrollBox.Add Child] (传入 NewItem)
                        │
                        ▼
                   [UAVIdArray.Add] (传入 UAVId)
                        │
                        ▼
                   [UAVItemArray.Add] (传入 NewItem)
                        │
                        ▼
                   [LastUpdateText.Set Text] (更新时间戳)
```

### ⚠️ 常见错误排查

| 错误现象 | 原因 | 解决方法 |
| :--- | :--- | :--- |
| 每次刷新都重复添加同一个无人机 | 循环体内忘记将 `bFound` 设为 `True`，导致 Completed 判断时始终为 False。 | 在 `Break` 之前，必须调用 `Set bFound = True`。 |
| 控件显示了数据，但颜色/文本异常 | `WBP_UAVListItem` 中的 `SetUAVState` 函数没写完整。 | 打开 `WBP_UAVListItem`，补全控件属性赋值逻辑。 |
| 运行时提示“访问无效对象” | 滚动框或数组变量未初始化（未绑定）。 | 检查 `UAVListScrollBox` 是否在 Designer 中勾选了“Is Variable”。 |

按照以上顺序逐一节点拖拽连接，就能完美实现“未找到则创建新条目”的逻辑。如果卡在某个具体节点（比如找不到 `Add Child` 或 `Add` 节点），建议直接从引脚拖出输入中文“添加”或英文“Add”搜索，通常能快速定位。
