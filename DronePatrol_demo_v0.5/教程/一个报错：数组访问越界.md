## 问题 1：Last Update Time 不变化

### 原因分析

最可能的原因是：在 `WBP_MultiUAVMonitor` 的 `OnStateUpdated` 事件中，**更新 `LastUpdateText` 的代码放在了条件分支内**（例如只在创建新条目时执行），而不是每次状态更新都执行。

### 修复方法

打开 `WBP_MultiUAVMonitor` 的事件图表，找到 `OnStateUpdated` 事件（或绑定到委托的事件）。确保逻辑结构如下：

```
OnStateUpdated (输入 NewState)
    ↓
[更新列表项逻辑]  ← 这部分你已经有了（创建或更新 UAVListItem）
    ↓
【必须在这里】更新 LastUpdateText  ← 确保这段代码在条件分支之外
    ↓
Get Current Time → 格式化为字符串 → Set Text (LastUpdateText)
```

#### 具体操作步骤：

1. 在 `WBP_MultiUAVMonitor` 的 `Event Graph` 中找到 `OnStateUpdated` 事件（可能是自定义事件或直接绑定委托）。
2. 在它的执行链末尾（所有条件判断之后），添加以下节点：
   - 右键搜索 **`Now`** 节点（或 **`Get Time Seconds`**）。
   - 将时间转换为字符串：使用 **`Format Text`** 节点，格式为 `{0}:{1}:{2}`，分别填入时、分、秒。
   - 连接 `LastUpdateText` → **`Set Text`**。
3. **重要**：确保这段代码不放在 `if` 分支内部，而是放在所有分支执行完毕之后。

## 问题 2：数组访问报错 (`CallFunc_Array_Get_Item_2`)

### 原因分析

这个报错是因为你在 `WBP_UAVListItem` 的 `SetUAVState` 函数中，**尝试访问了一个空数组或无效索引**。常见的错误场景：

- 在 `SetUAVState` 中使用了 `Get (a copy)` 或 `Get` 节点访问数组，但数组为空或索引越界。
- 或者在 `WBP_MultiUAVMonitor` 中更新列表时，`UAVItemsMap` 的键值查找失败，然后错误地尝试访问空对象。

### 排查与修复方法

#### 步骤 1：检查 `WBP_UAVListItem` 中的 `SetUAVState` 函数

1. 打开 `WBP_UAVListItem` 的事件图表。
2. 找到 `SetUAVState` 函数（输入参数为 `InState`）。
3. 仔细检查函数内的所有**数组访问**节点（如 `Get`、`Array Element` 等）。
4. **常见错误**：比如你有一个数组存储了“任务点”或“路径点”，但索引超出了范围。如果你没有使用数组，则可能是在设置文本时错误地使用了数组节点。

**临时解决方案**：在访问数组前添加 **`Is Valid Index`** 检查：

```
如果数组长度 > 索引
    则访问该元素
否则
    跳过或使用默认值
```

#### 步骤 2：检查 `WBP_MultiUAVMonitor` 中的 Map 访问

你之前在 `WBP_MultiUAVMonitor` 中维护了一个 `UAVItemsMap`（键为 `UAVId`，值为 `WBP_UAVListItem`）。报错可能是在这里：

- 当 `OnStateUpdated` 触发时，尝试从 Map 中获取条目，但键（UAVId）不存在或为 0。
- 然后错误地调用了空对象的 `SetUAVState`。

**修复方法**：

在访问 Map 之前，先检查该键是否存在：

1. 使用 **`Contains Key`** 节点检查 Map 中是否有该 UAVId。
2. 如果存在，才执行 `Get` 并调用 `SetUAVState`。
3. 如果不存在，则创建新条目。

**蓝图节点示例**：

```
OnStateUpdated (NewState)
    ↓
Break FUAVState (获取 UAVId)
    ↓
UAVItemsMap → Contains Key (UAVId)  ← 分支判断
    ├── True → UAVItemsMap → Get (UAVId) → SetUAVState(NewState)
    └── False → Create Widget (WBP_UAVListItem) → SetUAVState(NewState) → Add to ScrollBox → Add to Map
    ↓
(更新 LastUpdateText)
```

## 完整修复后的 `WBP_MultiUAVMonitor` 逻辑参考

我为你整理一份完整、安全的蓝图逻辑：

### 变量
- `UAVMonitorRef` (类型: `AUAVMonitor`)
- `UAVItemsMap` (类型: `Map<Int32, WBP_UAVListItem>`)
- `LastUpdateText` (类型: `TextBlock`，已在设计器中提升为变量)

### Event Construct
```
Event Construct
    ↓
Get All Actors of Class (AUAVMonitor) → Array Get (索引0) → Cast to AUAVMonitor → 赋值给 UAVMonitorRef
    ↓
UAVMonitorRef → Bind Event to OnUAVStateUpdated → 连接到自定义事件 OnStateUpdated
    ↓

```

### 自定义事件 OnStateUpdated (输入 NewState)
```
OnStateUpdated (NewState)
    ↓

    ↓

    ↓
```
