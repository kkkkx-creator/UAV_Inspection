好的，这部分是 UMG 蓝图可视化脚本的核心操作。既然你是 UE4 新手，我就把每一步拆解到**按钮级**，并且专门针对你问的“Border 颜色修改”给出最稳妥的傻瓜式操作。

## 准备工作（非常重要！）

在开始写代码之前，先确保你的 UI 控件可以被蓝图访问：

1. 打开 `WBP_UAVListItem` 设计器（Designer）。
2. 在左侧 **Hierarchy**（层级）面板中，依次点击以下控件，并在右侧 **Details**（细节）面板中，**勾选顶部的 `Is Variable`**（是变量）：
   - `UAVNameText`
   - `BatteryText`
   - `PositionText`
   - `SpeedText`
   - `TaskText`
   - `FaultText`
   - `StatusIcon`
   - `ItemBorder`（边框）
3. 保存并编译（点工具栏的 Compile 按钮）。

---

## 第一部分：创建函数和参数

1. 在 `WBP_UAVListItem` 中，切换到 **Graph**（图表）标签页（设计器旁边）。
2. 左侧 **My Blueprint**（我的蓝图）面板中，找到 **Functions**（函数）分类，点击它旁边的 **`+`** 号。
3. 新函数默认会高亮，直接重命名为 **`SetUAVState`**（按回车确认）。
4. 在右侧 **Details**（细节）面板中（此时显示的是函数的属性），找到 **Inputs**（输入）区域，点击 **`+`** 号添加一个参数：
   - 参数名称：`InState`
   - 参数类型：点击下拉框，搜索 `Structure`，在结构体列表中找到 **`FUAVState`** 并选中。
5. 此时函数图表会自动打开（如果没打开，双击左侧 Functions 下的 `SetUAVState`）。

---

## 第二部分：分解结构体数据（Break）

1. 在函数图表（`SetUAVState` 的图表）中，找到你刚创建的输入参数节点 **`InState`**（一个带紫色引脚的小圆点）。
2. **鼠标左键按住 `InState` 引脚往外拖**，松开，在弹出的菜单中搜索 `Break FUAVState`（或者直接输入 `Break`），点击选择。
3. 现在你会看到 `InState` 被拆解成很多小引脚：`UAVId`、`Position`、`BatteryPercent`、`TaskType` 等等。

---

## 第三部分：设置各文本控件的文本（Text）

**原理**：把数据转换成字符串，然后塞进控件的 `Set Text` 节点。

**以 `UAVNameText` 为例**（其他同理）：
1. 从 `Break` 引脚拖出 **`UAVId`**（整数） → 搜索 **`Int To String`**（整数转字符串）节点，点击。
2. 打字输入 **`"UAV "`**（注意带引号，表示文本常量）→ 按住它拖出，搜索 **`Append`**（追加）节点。
3. 将 `Int To String` 的输出连接到 `Append` 的 **`A`** 或 **`B`** 引脚（哪个都行）。
4. 在图表空白处右键，搜索 **`UAVNameText`** → 选择 **`Set Text (UAVNameText)`**。
5. 将 `Append` 的输出结果，连接到 `Set Text` 节点的 **`In Text`** 引脚。

**其他字段按此逻辑操作**：

| 控件 | 数据来源（从 Break 拖出） | 文本拼接示例 |
| :--- | :--- | :--- |
| `BatteryText` | `BatteryPercent` (Float) | `"电量: "` + 转字符串 + `"%"` |
| `PositionText` | `Position` (Vector) | 比较复杂，建议先忽略 Z 轴：`"位置: ("` + `X转字符串` + `", "` + `Y转字符串` + `")"`（用多个 Append 串联）。 |
| `SpeedText` | `SpeedKmh` (Float) | `"速度: "` + 转字符串 + `" km/h"` |
| `TaskText` | `TaskType` (String) 和 `TaskProgress` (Float) | `"任务: "` + `TaskType` + `" \| "` + (进度*100转字符串) + `"%"` |

> **提示**：对于 `PositionText`，如果你觉得多个 Append 太麻烦，可以使用 **`Format Text`** 节点，它支持 `{0}` 占位符，更简单。

## 第四部分：故障与电量逻辑（核心颜色变化）

这里需要做**条件判断**。UE4 蓝图使用 **`Branch`**（分支）节点。

### 逻辑顺序（先判断故障，再判断电量）：
1.  **检查故障**：`bHasFault == True` → 红色。
2.  **否则检查低电量**：`BatteryPercent < 20` → 黄色。
3.  **其他正常情况**：绿色。

### 具体操作步骤：

**1. 拖动判断节点**：
- 从 `Break` 节点拖出 **`bHasFault`**（布尔值），弹出菜单选择 **`Branch`**（分支）。
- 此时你会得到一个菱形节点，带 `Condition`（条件）、`True`（真）和 `False`（假）引脚。

**2. 在 True（故障）分支上设置红色**：
- 在图表空白处右键，搜索 **`Set Brush Color`**，点击。（这是专门设置边框颜色的节点）
- 在弹出的对象选择中，**选择 `ItemBorder`**（你的边框控件）。
- 在 `Set Brush Color` 节点下方，有一个 **`In Color and Opacity`** 引脚。
- 右键点击该引脚，搜索 **`Make Linear Color`**。
- 将 `Make Linear Color` 的 R（红）设为 **1.0**，G（绿）设为 **0.0**，B（蓝）设为 **0.0**，A（透明度）设为 **1.0**。
- **同理**，设置状态图标 `StatusIcon` 的颜色：右键搜索 `Set Color and Opacity (StatusIcon)`，也连上这个红色。
- **设置故障文字可见**：右键搜索 **`Set Visibility (FaultText)`**，将 `In Visibility` 设为 **`Visible`**。同时，将 `FaultText` 的 `Set Text` 设置为 `"�7�2 " + FaultType`（从 Break 节点取 `FaultType`）。

**3. 在 False（非故障）分支上继续判断电量**：
- 从 `Branch` 的 **`False`** 引脚拖出一条线，再拖一个 **`Branch`**。
- 这次的条件从 Break 节点拖出 **`BatteryPercent`**，搜索 **`<`**（小于）节点，将值设为 **20.0**。将这 `<` 节点的输出（布尔值）连接到第二个 `Branch` 的 `Condition`。
- **True（低电量）**：颜色设为黄色（R=1.0, G=0.8, B=0.0, A=1.0）。`FaultText` 设为 **`Hidden`**（隐藏）。
- **False（正常）**：颜色设为绿色（R=0.0, G=0.8, B=0.0, A=1.0）。`FaultText` 设为 **`Hidden`**。

## 第五部分：重点解决“Border 颜色修改”的疑问

你特意问了“修改 Border 的 Brush Color”。在蓝图中，Border 控件的颜色不是直接改 `Brush Color` 属性，而是通过 **`Set Brush Color`** 这个函数节点。

**如果你在右键搜索时找不到 `Set Brush Color`**，请按以下方法操作：
1. 在左侧 **My Blueprint** 的 **Variables**（变量）中找到 `ItemBorder`（因为刚才我们把它设为了变量）。
2. 将 `ItemBorder` 变量**直接拖进图表**，变成一个蓝色的对象节点。
3. **鼠标左键按住这个蓝色节点的引脚往外拖**，松开，在弹出的菜单中直接搜索 **`Set Brush Color`**，它一定会出现。
4. 这个节点的全称是 `Set Brush Color (Border)`，就是你要用的。

## 最终检查清单

完成所有连线后，你的函数图表应该是一个从 `InState` 开始，经过 Break，分支出三条颜色路径（红/黄/绿）的树状结构。

1. 点击工具栏的 **Compile**（编译）。
2. 没有红色报错，说明函数逻辑正确。
3. 保存蓝图。

## 调试建议（避免看不到颜色变化）

如果运行后颜色没变，可能是以下原因：
- **Border 的 Draw As** 设置问题：在设计器中选中 `ItemBorder`，在 Details 中找到 **Brush** 下的 **Draw As**，确保它不是 **`None`**，可以选择 **`Border`** 或 **`Solid Color`**，否则颜色不显示。
- **透明度**：确保你的 `Make Linear Color` 节点的 A（Alpha）值为 **1.0**。

按这个一步步操作，即使没接触过蓝图也能顺利完成。如果某个节点找不到（比如 `Append` 或 `Format Text`），可以在搜索框输入英文名，UE4 支持中英文模糊搜索。完成这一步后，就可以回到主界面去绑定数据了。
